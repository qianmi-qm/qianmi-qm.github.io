这个博客长什么样，其实是我先说清楚"要什么"，再让 AI 把代码写出来的。配色、形状、排版怎么定，我说了算；HTML / CSS / JS 具体怎么敲，交给 AI。

一、规矩定好了，页面不烧心

我的灵感来自于音游的一些矢量楔形cd封面，偏向平面设计

先立三条规矩：

  1. 颜色就三种：黑、白、荧光绿。灰阶只当过渡，别的色儿一律不准露头。
  2. 绿色只当点缀：面积压在 10% 上下。它一旦成了主色，页面会显得十分塑料。
  3. 不许有圆角，不许规规矩矩：容器、色块、过渡带都得带角度，横平竖直只留给文字排版。

二、把想法变成一行行变量

想法定完，第一步不是憋组件，而是先把它翻译成CSS变量。颜色、字体、间距全塞进变量里，后面所有组件都只引用变量——想换配色就改一处。

:root {
  --ink:   #000000;   /* 纯黑：跑马灯文字等 */
  --bg:    #050706;   /* 基底：近黑 */
  --bg-2:  #0b0e0c;   /* 交替区块：比基底亮一档 */
  --bg-3:  #121614;
  --bg-4:  #1a201c;
  --paper: #ffffff;   /* 纯白：主文字与碎片 */

  --neon:  #00ff41;   /* 荧光绿：唯一强调色 */

  --mono: "JetBrains Mono", ui-monospace, Consolas, monospace;
  --cjk:  "Noto Sans SC", -apple-system, "PingFang SC", sans-serif;

  --cut:    18px;                        /* 斜切角尺寸 */
  --strip-h: clamp(9px, 1.2vw, 13px);    /* 跑马灯下方装饰条高度 */
  --ease:   cubic-bezier(0.16, 1, 0.3, 1);
}

三、配饰点缀一下

首页背景那片放射状的碎片，让整套设计在视觉上更有风格，不显得空旷的同时也不会显得杂乱无章。

所以我的做法是让代码去画。跟 AI 来回改了好几版，最后稳定成三种基本形状：闪电、细长三角、楔形。它们都从一个焦点出发，顺着主方向往外飞。

/* 闪电：中轴按折线摆动，宽度从根部渐缩到尖端收 0 */
function bolt(rnd, bx, by, ang, len, w0, kink) {
  var dx = Math.cos(ang), dy = Math.sin(ang);
  var nx = -dy, ny = dx;

  var stops = [0, 0.26, 0.5, 0.74, 1];
  var zig   = [0, kink, -kink * 0.8, kink * 0.55, 0];
  var spine = [];
  var i, t, half;

  for (i = 0; i < stops.length; i++) {
    t = stops[i] + (rnd() - 0.5) * 0.05;
    spine.push([
      bx + dx * len * t + nx * zig[i],
      by + dy * len * t + ny * zig[i]
    ]);
  }

  var outline = [];
  /* 右侧边（根 → 尖） */
  for (i = 0; i < spine.length - 1; i++) {
    half = w0 * (1 - stops[i]) * (0.7 + rnd() * 0.5);
    outline.push([spine[i][0] + nx * half, spine[i][1] + ny * half]);
  }
  /* 尖端收成一点 */
  outline.push([spine[spine.length - 1][0], spine[spine.length - 1][1]]);
  /* 左侧边（尖 → 根） */
  for (i = spine.length - 2; i >= 0; i--) {
    half = w0 * (1 - stops[i]) * (0.7 + rnd() * 0.5);
    outline.push([spine[i][0] - nx * half, spine[i][1] - ny * half]);
  }
  return outline;
}

三个参数决定最终长啥样：

  • kink：闪电的折角幅度。太小像根直线，太大直接断，16 ~ 26 是甜区。
  • len：得拉到足够冲出画布，碎片才是"从画面外冲进来"的，而不是贴上去的贴纸。
  • w0：根部宽度。配上 (1 - t) 的线性收缩，每根闪电就都是根粗尖细，自带方向感。

现在的碎片场是八个图层叠出来的，顺序固定，每层各管一件事：

层内容作用
0氛围雾块极大极淡，先压住背景
1闪电（4~6 根）主视觉，起点围绕焦点铺开
2细三角针群低视觉重量的点缀
3楔形制造"断裂"的对比
4对角宽梁贯穿画面的结构线
5切缝底色楔形，切出裂缝与纵深
6水平细线组横贯线 + 刻度齿，接上"工程图纸"的气质
7十字标记定位用的十字点
随机数用的是 mulberry32 这种带种子的伪随机，没用 Math.random()。好处是每个页面配一个固定 seed，刷新多少次都长一个样；不然用户每刷一次背景就换一张，会显得冲撞。而且同一个 seed 必定复现同一张图，调参的时候心里有底——调烦了，换个 seed 就是新画面，之前满意的构图也不会丢。

最后再给这一整块加层滚动视差：监听到滚动，就用 requestAnimationFrame 把位移写进 transform（translate3d 加一点点放大），还用一个 ticking 标志位做节流，保证一帧只算一次。位移很小，成本极低，但滚起来就有纵深了，不至于像张死图。

四、元素不可杂乱

全站不许有圆角，靠的就是 clip-path。按钮、卡片、代码块都切掉一个对角：

.btn {
  box-shadow: inset 0 0 0 2px var(--paper);
  clip-path: polygon(0 0, calc(100% - var(--cut)) 0, 100% var(--cut),
    100% 100%, var(--cut) 100%, 0 calc(100% - var(--cut)));
}
.btn:hover {
  transform: translate(-4px, -4px);
  box-shadow: inset 0 0 0 2px var(--neon), 5px 5px 0 var(--neon);
  color: var(--neon);
}

鼠标一放上去就往左上挪一点，右下角再拍出一块实心的荧光绿影子——这种"错位硬阴影"是海报常用的手法，比柔和的 box-shadow 更配这套锐利的调子。注意这里用的是 inset 描边而不是边框，这样切角处的线才能跟着多边形走，不会在角落漏出个直角。

区块之间那条斜线接缝，一个容器，背景铺上一块的颜色，里面的伪元素铺满、填下一块的颜色，再给它切个三角。

.slant {
  position: relative;
  height: clamp(38px, 5vw, 78px);
  background: var(--a, var(--bg));          /* 上一块的颜色 */
}
.slant::after {
  content: "";
  position: absolute;
  inset: 0;
  background: var(--b, var(--bg-2));        /* 下一块的颜色 */
  clip-path: polygon(0 100%, 100% 0, 100% 100%);
}

/* 用修饰类把两端的颜色配好，页面里只写一个类名 */
.slant--ink-2  { --a: var(--bg);   --b: var(--bg-2); }
.slant--2-ink  { --a: var(--bg-2); --b: var(--bg);   }

这样接缝天生严丝合缝，不用算负 margin，也不怕响应式下高度变来变去；再加个 .slant--rev 把三角翻个方向，坡度的朝向就反过来了。

五、跑马灯：让页面动起来的那根线

每个页面在页头下面都有一条滚动字幕。它更像是一条腰带，修饰你的腰线，与此同时赋予画面动感。它固定是三件套，顺序每个页面都一样：

① 指示器：一根竖线 + 一个绿点 + SCROLL 字样，告诉你下面还有东西。 ② 跑马灯：荧光绿底、黑字的横条，从左往右跑，鼠标一悬停就停。 ③ 装饰条：跑马灯正下方一条通栏荧光绿，带斜向细纹。

.ticker {
  background: var(--neon);
  color: var(--ink);
  overflow: hidden;
  /* 关键：让文字在「跑马灯 + 下方装饰条」整块绿里上下等距 */
  padding-top:    calc(0.85rem + var(--strip-h) / 2);
  padding-bottom: calc(0.85rem - var(--strip-h) / 2);
}
.ticker__track {
  display: flex;
  width: max-content;
  animation: ticker-run 40s linear infinite;
}
.ticker:hover .ticker__track { animation-play-state: paused; }
@keyframes ticker-run {
  from { transform: translateX(-50%); }
  to   { transform: translateX(0); }
}
.neon-bar {
  height: var(--strip-h);
  background-color: var(--neon);
  background-image: repeating-linear-gradient(
    -45deg, rgba(0, 0, 0, 0.28) 0 3px, transparent 3px 9px
  );
}

六、故障字和滚动进场

大标题上有个小故障闪一下：鼠标移上去，字会红绿错位出重影。做法是只给标题加个 data-glitch，JS 自己往里塞两层副本（--a / --b），再配 CSS 的错位动画。这样 HTML 里不用手写三份字，也不会让读屏软件重复念（副本都带 aria-hidden）。

内容进场那个"滚动揭示"我用的是 IntersectionObserver，没去监听 scroll 自己算位置——元素进视口才加 is-in 触发淡入，而且触发一次就 unobserve，不会反复算。每个元素还能用 data-delay 错开进场时间，就有那种依次浮现的节奏。

七、我出主意，AI 写代码

整套代码是 AI 写的，但写什么、按什么规矩写，需要自己定夺。这个分工得说清楚，因为它决定了成品到底像不像"个人名片"。

我干的活：定三条颜色规矩、定形状只用闪电 / 三角 / 楔形、定绿色占比上限、定"碎片必须铺满全屏还得疏密错落"、定每个页面的 seed 不能重样、定跑马灯三件套的结构。

丢给 AI 的活：把规矩翻译成几何计算、写出生成器函数、实现 clip-path 的锐角裁切、把响应式断点补齐、把跑马灯的无缝循环调通。

八、零依赖、零构建

整个站最后就三样东西：一个 CSS 文件、一个 JS 文件、几个 HTML 页面。没有 npm，没有打包器，没有框架，没有构建这一步。

博客作为一个纯静态的内容站，没状态管理、没路由、没数据请求——引一套前端工具链进来，换来的是每改一篇文章都要等构建，外加一个几百 MB 的 node_modules。就几个页面的站，这账不划算。

代价是有些 HTML 得手写重复（比如每个页面都得复制一遍导航和页脚）。但就这体量，重复的成本远低于养一套模板引擎或者静态站点生成器。知道什么时候不该上工具，和会用工具一样重要。

九、扔到 GitHub Pages 上，让它一直在线

站点托管在 GitHub Pages 上，仓库名必须是 <用户名>.github.io 这个固定格式，这样网址才干净：https://用户名.github.io，不带任何子路径。

上线前有两个文件必须准备好：

  • .nojekyll：一个空文件，告诉 GitHub Pages 别走 Jekyll 处理，直接按静态文件原样发。没它，以下划线开头的文件或目录会被吞掉。
  • .gitignore：挡掉系统文件和编辑器配置，别把没用的东西提交上去。
# 首次发布
git init -b main
git add -A
git commit -m "init: blog"
git remote add origin https://github.com/<用户名>/<用户名>.github.io.git
git push -u origin main

# 之后每次更新文章，只要三条命令
git add -A
git commit -m "post: 新增文章 xxx"
git push

推完 GitHub 会自动构建一次，一两分钟新内容就生效，不用去仓库设置里来回点。Pages 是免费的，也没到期日，只要仓库在，站就一直在线。

Ps：国内访问 GitHub 不稳，表现就是 TCP 能握手、但 TLS 请求时不时被掐断，push隔三差五失败。这不是配置错，一般重试几次或者用加速器（例如watt toolkit）就过了。不过这种不稳只影响上传；站发布后是 GitHub 的 CDN 对外服务的，访问速度不受影响。

结语

这项目真正的点在于你的设计思路：用几种颜色、绿色占多少、碎片怎么分布、区块怎么衔接、动线放哪。代码只是这些决定的结果， AI的确能替我把代码写完，然而前端的表现如何还要取决于你自己的想法。

你要是也想搞类似的视觉，建议从先定约束开始：规定好只能用哪三种颜色、哪些形状禁止出现、什么情况不加元素，剩下的决定会突然简单很多。毕竟，规矩立住了，才不烧心。
